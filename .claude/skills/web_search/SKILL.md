# 网络搜索技能（Tavily 版本）

## 目的

此技能使AI Agent能够：
- 通过 Tavily API 从互联网搜索引擎中检索最新的信息和数据
- 获取通用医学知识、药物信息、疾病百科等
- 补充患者特定信息之外的背景知识
- 查询实时的新闻、指南和最佳实践

此技能用于获取公开的、非患者隐私的信息，与mysql_query（患者私密数据）形成互补。

## When to Use

- 用户询问通用医学知识（例如"高血压的症状是什么？"）
- 需要查询特定药物的信息、用法、副作用
- 用户问题涉及最新的医疗指南或研究
- 询问疾病的定义、病因、传播方式等常识性问题
- 需要获取互联网上的实时信息或资源

## Steps

1. 从用户的查询中提取搜索关键词
2. 根据关键词生成合适的搜索查询语句
3. 调用 Tavily 搜索接口获取相关的搜索结果
4. 返回格式化的搜索结果，包含标题、摘要、链接和相关性评分
5. Agent根据搜索结果生成最终的回答

## 参数说明 (Fields)

### query
- 类型: String
- 必填: 是
- 描述: 搜索关键词，应该简洁清晰地表达用户的信息需求
- 示例: "高血压治疗指南", "阿司匹林副作用", "皮肤病分类"

### max_results
- 类型: Integer
- 必填: 否
- 默认值: 3
- 范围: 1-5
- 描述: 返回的最大搜索结果数

### search_depth
- 类型: String
- 必填: 否
- 默认值: "advanced"
- 可选值: "basic" 或 "advanced"
- 描述: 搜索深度
  - **basic**: 快速搜索，返回高相关性结果
  - **advanced**: 深度搜索，更全面的结果但耗时更长


## Examples

### 场景 1：查询药物信息
- **用户**: "请告诉我阿司匹林的用途和副作用"
- **操作**:
  ```json
  {
    "query": "阿司匹林用途副作用",
    "max_results": 3,
    "search_depth": "advanced"
  }
  ```
- **预期结果**: 返回关于阿司匹林的医学信息、用途、常见副作用等，包括相关性评分

### 场景 2：医学常识查询
- **用户**: "高血压有什么症状？"
- **操作**:
  ```json
  {
    "query": "高血压症状表现",
    "max_results": 2,
    "search_depth": "basic"
  }
  ```
- **预期结果**: 返回高血压症状的相关信息，优先级排序

### 场景 3：疾病百科查询
- **用户**: "皮肤癣是怎么传播的？"
- **操作**:
  ```json
  {
    "query": "皮肤癣传播方式",
    "max_results": 3,
    "search_depth": "advanced",
  }
  ```
- **预期结果**: 返回来自医学权威网站的皮肤癣传播途径信息

### 场景 4：排除特定来源的搜索
- **用户**: "新冠疫苗的最新研究"
- **操作**:
  ```json
  {
    "query": "COVID-19 vaccine research 2026",
    "max_results": 5,
    "search_depth": "advanced",
  }
  ```
- **预期结果**: 返回排除社交媒体的最新疫苗研究信息

## Return Structure

搜索结果返回以下结构：

```python
{
  "query": str,                    # 原始搜索查询
  "source": "tavily",              # 数据来源
  "results": [
    {
      "rank": int,                 # 结果排序
      "title": str,                # 网页标题
      "url": str,                  # 网页链接
      "snippet": str,              # 内容摘要
      "relevance_score": float,    # 相关性评分 (0-1)
      "published_date": str        # 发布日期（如果可用）
    }
  ],
  "timestamp": str,                # 搜索执行时间 (ISO 8601)
  "total_results": int             # 返回结果总数
}
```

## Constraints

### 适用范围
- 仅用于查询通用医学知识和公开信息
- 不能用于查询患者特定的隐私医疗数据（应该用 mysql_query）
- 不能代替专业医生的诊断和建议

### 内容质量
- 返回的是搜索结果摘要，不一定是完整准确的医学知识
- 用户应该验证重要的医学信息
- 对于诊疗建议，应该咨询专业医生
- 相关性评分仅供参考，高分数不保证信息准确性

## 错误示例 (反例) - 请避免以下行为

### 反例 1：搜索关键词过于宽泛或不清楚
- **用户**: "告诉我关于医学的所有东西"
- **错误操作**: `{"query": "医学", "max_results": 20}`
- **原因**: 搜索词过于宽泛，返回的结果不会有用，并浪费 API 配额
- **正确操作**: 细化搜索词，例如 `{"query": "皮肤病分类"}` 或 `{"query": "常见皮肤病症状"}`

### 反例 2：期望搜索结果能代替医生诊断
- **用户**: "我有皮肤瘙痒，请诊断我"
- **错误操作**: 使用 `web_search` 搜索后直接给出诊断
- **原因**: 网络搜索的结果不能代替医生的专业诊断
- **正确操作**: 根据搜索结果提供信息和建议，但要明确指出用户应该咨询医生进行正式诊断

### 反例 3：使用错误的搜索深度
- **用户**: "快速查询一个词的定义"
- **错误操作**: `{"query": "definition", "search_depth": "advanced", "max_results": 20}`
- **原因**: 对于简单查询使用高级搜索会浪费时间和 API 资源
- **正确操作**: 对于快速查询使用 `{"search_depth": "basic", "max_results": 3}`


## 重要说明
- 搜索结果仅供参考，不构成医学建议
- 对于重要的医疗决策，应该咨询医学专业人士
- Agent 应该在使用搜索结果时注明来源和相关性评分
- 搜索结果的质量取决于搜索词的精准度，建议使用具体的医学术语
- Tavily API 提供的相关性评分是基于 AI 模型的评估，可能存在偏差
- 某些医学信息可能需要多个来源验证以确保准确性
