# Milvus向量数据库技能

## 目的
此技能使 AI Agent能够：
- 使用查询向量搜索最近邻
- 模型仅通过发出命令行界面（CLI）命令与系统进行交互。
- 所有检索逻辑和数据库访问都在本地处理。

## When to Use
当用户请求关于药物、疾病或医学知识的信息时使用此技能，包括：
- 药物信息（成分、用法、副作用等）
- 疾病百科（症状、诊断、治疗等）
- 胃肠病学专业知识
- 医学参考资料和最佳实践

## Steps
1. 从用户的问题中识别需要查询的医学主题（药物、疾病或医学知识）
2. 确定应该查询的集合（drug_vector、disease_vector 或 gastroenterology_vector）
3. 将用户的自然语言问题转换为精炼的查询关键词
4. 向向量数据库发出搜索请求
5. 返回相关的医学知识和参考信息

## Examples
支持对药物（drug_vector）、胃肠病学知识（gastroenterology_vector）和疾病信息（disease_vector）进行向量检索。
可以一次性查询多个集合。

## 参数说明 (Fields)

### operation
- 固定值: "search"
- 描述: 执行向量检索操作。

### skill_list
- 类型: List[Object]
- 描述: 包含一个或多个检索请求的列表。

#### 列表项字段说明 (MilvusSkillItem)
1. **name** (必须)
   - 描述: 要查询的向量集合名称。
   - 可选值:
     - `drug_vector`: 药物信息库（查药品、剂量、副作用等）。
     - `gastroenterology_vector`: 胃肠病学知识库（查机制、症状、治疗原则等）。
     - `disease_vector`: 疾病信息库（查疾病表现、归属范畴等）。

2. **query** (必须)
   - 描述: 用于检索的自然语言查询文本。
   - 建议: 针对不同的集合使用相关的关键词。


## Examples

### 场景 1：查询药物信息 (drug_vector) - 单阶段模式
- **意图**: 用户询问"阿莫西林的作用"。
- **操作**: `name="drug_vector"`, `query="阿莫西林的作用"`（不设置recall_k）
- **预期结果**: 返回阿莫西林的药物信息、用法用量、副作用等（原有单阶段逻辑）

### 场景 2：查询疾病信息 - 两阶段模式（NEW in v2.0）
- **意图**: 用户问"痤疮怎么治疗"。
- **操作**:
  ```json
  {
    "name": "disease_vector",
    "query": "痤疮 (青春痘) 治疗方法",
  }
  ```
- **预期结果**：
  - 阶段1：从disease_vector召回20条相似度最高的结果
  - 阶段2：LLM评估这20条的语义相关性，返回最相关的3条
  - 好处：避免相似度排序与语义相关性不一致的问题

### 场景 3：查询胃肠病学知识 (gastroenterology_vector)
- **意图**: 用户问"胃溃疡和胃炎有什么区别？"
- **操作**: `name="gastroenterology_vector"`, `query="胃溃疡 与 胃炎 的 区别"`
- **预期结果**: 返回两种疾病的区别、症状、诊断标准

### 场景 4：单库多点查询 (针对复杂问题深入挖掘)
- **意图**: 用户问"长青春痘（痤疮）怎么调理，留下的痘印能去掉吗？"
- **操作**: 针对同一个库发起多次不同维度的查询：
    1. `disease_vector`: `query="痤疮 (青春痘) 日常护理与调理"` (查护理)
    2. `disease_vector`: `query="痘印 痘坑 修复方法"` (查后遗症处理)
- **预期结果**: 返回痤疮的调理方法和痘印的修复建议

### 场景 5：综合问诊 (多库联合)
- **意图**: 用户说"我脸上长了很多红疹子，很痒，是湿疹吗？"。
- **操作**: 这是一个复杂问题，建议同时查询多个库：
    1. `gastroenterology_vector`: 查询 "面部红疹伴瘙痒的可能原因" (查找潜在病理)
    2. `drug_vector`: 查询 "治疗湿疹和皮炎的常用药膏" (查找药物)
    3. `disease_vector`: 查询 "湿疹的典型症状与表现" (鉴别诊断)
- **预期结果**: 返回多角度的医学知识，帮助 agent 进行综合判断

## Constraints

### 知识库限制
- 仅支持三个集合：drug_vector、gastroenterology_vector、disease_vector
- 数据来自事先构建的向量数据库，可能不是实时更新
- 搜索结果基于相似度匹配，可能不是完全精确

### 查询限制
- 查询必须是自然语言文本，不支持结构化查询
- 查询关键词应该精炼，避免过长的描述
- 单个查询应该聚焦于一个主题

### 数据准确性
- 检索结果来自医学知识库，但可能存在过时或不完全的信息
- 结果仅供参考，不能替代正式的医学诊断
- 对于罕见疾病或新兴医学知识，可能没有相关信息

## 错误示例 (反例) - 请避免以下行为

### 反例 1：幻觉集合名称
- **用户**: "我想查查心脏病的资料。"
- **错误操作**: `name="cardiology_vector"` (错误：该集合不存在)
- **正确操作**: `name="disease_vector"` (正确：映射到现有的通用疾病集合)

### 反例 2：直接复制冗长用户输入
- **用户**: "医生我这几天感觉头特别疼，就像要炸开一样，而且还有点恶心，不知道是不是昨天吹空调吹的..."
- **错误操作**: `query="医生我这几天感觉头特别疼，就像要炸开一样，而且还有点恶心，不知道是不是昨天吹空调吹的..."` (错误：噪音太多)
- **正确操作**: `query="剧烈头痛 伴随恶心 常见原因"` (正确：提炼关键症状)

### 反例 3：无关请求
- **用户**: "今天北京天气怎么样？"
- **错误操作**: 调用 `milvus_query`
- **正确操作**: **不要调用此技能** (本技能仅用于医学知识检索)
