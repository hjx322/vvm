## 🎯 关键文件详解

### 1️⃣ **agent/digital_smart_doctor_agent.py**
**字数**：~600行 | **重要性**：⭐⭐⭐⭐⭐ | **修改频率**：低

**职责**：
- Agent整体协调
- MySQL连接管理（心跳、重连）
- LangGraph工作流创建和执行
- 状态管理和恢复

**核心方法**：
```python
__init__()                    # 初始化
create_workflow()             # 创建状态机
invoke()                      # 执行推理
_create_connection()          # 连接(3次重试)
_start_ping_task()            # 启动心跳
_ping_loop()                  # 心跳检测(60秒)
_ensure_connection_alive()    # 连接验证
close()                       # 清理资源
```

---

### 2️⃣ **agent/core/state.py**
**字数**：~150行 | **重要性**：⭐⭐⭐⭐⭐ | **修改频率**：中

**职责**：定义对话状态机的所有字段

**核心字段**：
```python
# 对话字段
human_input: str                      # 用户输入
messages: list[BaseMessage]           # 对话历史

# 患者信息
medical_record_no: str                # 患者号
patient_info: dict                    # 基本信息
patient_visit_record: dict            # 就诊记录
patient_examine_result: dict          # 检查结果

# 图片处理
image_path: str                       # 图片路径
image_description: str                # Vision API描述
image_processing_status: str          # 处理状态
image_available_skills: list[str]     # 推荐技能

# 技能执行
sub_agent_input: dict                 # 技能参数/结果
```

## 🔄 代码流向示意

### 用户查询 "患者信息是什么？"

```
1. main.py
   ↓
2. DigitalSmartDoctorAgent.invoke()
   ↓
3. LangGraph开始执行:

   PreProcessNode
   ├─ 检测: 无图片
   ├─ 继续流程
   └─ state.image_path = None
      ↓
   RoutingNode
   ├─ 检测: 无图片处理状态
   ├─ 检测: 需要查询
   └─ 路由 → SkillQueryNode
      ↓
   SkillQueryNode
   ├─ LLM分析: 需要mysql_query技能
   ├─ skills/mysql_query_skill.py 执行
   ├─ .claude/skills/mysql_query/scripts/search.py
   │  └─ search_with_retry()
   │     └─ MySQL连接 + 查询 + 格式化
   ├─ 返回结果
   └─ state.sub_agent_input = {患者数据}
      ↓
   ChatNode
   ├─ 调用LLM (DashScope QWEN Plus)
   ├─ 输入: 用户查询 + 患者数据 + 对话历史
   ├─ LLM生成回答
   └─ state.final_answer = "根据查询，该患者..."
      ↓
   PostProcessNode
   ├─ 格式化输出
   └─ 返回用户
      ↓
4. main.py 显示结果
```

### 如何添加新技能

   ```
   .claude/skills/my_skill/
   ├── SKILL.md              (文档)
   └── scripts/my_script.py  (实现)
   ```

   ```
   skills/my_skill_handler.py
   ```

3. **注册到registry**
   ```python
   # skills/registry.py
   "my_skill": MySkillHandler()
   ```

4. **同步OpenSkills**
   ```bash
   openskills sync
   ```
